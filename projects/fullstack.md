# Full-Stack Engineering

Production-oriented full-stack systems: APIs, front-ends, databases, and
deployment.

## Areas

- **Front-end:** React, Next.js, TypeScript — component systems, state, SSR/SSG.
- **Back-end:** Node.js, Go, Python — REST and event-driven services.
- **Data:** PostgreSQL, MongoDB, Redis-style caching, queue-based processing.
- **Ops:** Docker, CI/CD on GitHub Actions, Vercel, Supabase, AWS.

## Selected work

- **MapCap IPO Platform** — TypeScript · Node · MongoDB (see
  [projects/web3](web3.md) and [full-stack case study](../case-studies/systems-engineering.md)).
- **Steinheim ERP & Invoicing** — enterprise system built for S.I.G / Steinheim,
  in production today (private).
- **Invoice & stock-flow tooling** — invoicing, stock-flow, and operational
  dashboards.

## Principles

1. **Type everything.** Interfaces are contracts, not suggestions.
2. **Test the seams.** Business logic is unit-tested; integrations are faked.
3. **Ship small.** Every change is reviewable and deployable on its own.

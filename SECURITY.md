# Security Policy

## Supported Versions

This repository is a **portfolio / documentation** project. There is no
long-running release channel; `main` is always the current content.

| Version | Supported |
| --- | --- |
| `main` | ✅ Supported |

## Reporting a Vulnerability

This repository contains no production code, but mistakes matter — an incorrect
claim or a broken link is still a defect.

- **Do not** open a public issue for security-relevant findings.
- Report privately via a **GitHub Security Advisory** on this repository, or
  contact the author directly through the links on the profile.

Please include:
1. The exact file and line involved.
2. Why you believe it is a problem (broken claim, misleading statement,
   sensitive data exposure, broken dependency reference, etc.).
3. A suggested fix, if you have one.

## Disclosure

I aim to acknowledge reports within **3 business days** and resolve confirmed
issues promptly. Non-sensitive corrections (typos, stale links) are welcome as
normal issues or pull requests.
